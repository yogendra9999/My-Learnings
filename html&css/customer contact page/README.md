# Customer Contact Page

A modern and responsive **Customer Contact Page** developed using **HTML5** and **CSS3**. This project was created as part of the **HTML & CSS Practical Record Manual – Task 7**. It features a clean corporate design with a navigation bar, hero section, contact information, contact form, location map, and footer.

---

## 📌 Features

- Responsive layout
- Modern navigation bar
- Hero section with background image
- Contact information cards
- Customer contact form
- Location map section
- Professional footer
- Clean and modern UI
- HTML5 semantic structure
- External CSS stylesheet
- Flexbox-based layout
- Rounded corners and box shadows

---

## 🛠 Technologies Used

- CSS3

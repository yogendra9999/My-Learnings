# SSIT Solutions — Corporate Website

A professional and responsive corporate website developed for **SSIT Solutions** using HTML5 and CSS3. The website presents the company's services, projects, client testimonials, company information, contact details, and business-focused call-to-action sections.

## 📌 Project Overview

The SSIT Solutions website is designed with a modern corporate interface using a clean blue, white, and gray color palette. The layout uses CSS Grid and Flexbox to create a structured and responsive design for desktop, tablet, and mobile screen sizes.

## ✨ Features

* Professional corporate website design
* Responsive desktop, tablet, and mobile layout
* Navigation bar with section links
* Hero section with call-to-action buttons
* Services section with five service cards
* About Us section with Mission, Vision, and Values
* Company statistics section
* Featured Projects section
* Client Testimonials section
* Call-to-Action section
* Contact information and contact form
* Professional footer with quick links and services
* Hover effects on buttons and cards
* Smooth scrolling navigation
* Modern card-based UI
* Accessible image `alt` text

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Grid
* Flexbox
* Responsive Media Queries

## 🎨 Design

The website follows a professional corporate design system:

* **Primary Color:** `#2563EB`
* **Background:** White
* **Secondary Background:** Light Gray
* **Text:** Dark Navy / Gray
* Rounded cards and buttons
* Subtle shadows
* Clean spacing and typography

## 📱 Responsiveness

Responsive CSS media queries are included for:

* Desktop
* Tablet — up to `992px`
* Mobile — up to `768px`

The layout adapts the navigation, hero, service cards, project cards, testimonials, contact form, and footer for smaller screens.

## 🚀 How to Run

1. Clone or download this repository.

2. Open the project folder.

3. Make sure the HTML, CSS, and `assets` files are in the correct locations.

4. Open `index.html` in a web browser.

No additional installation or dependencies are required.

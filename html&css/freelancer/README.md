# Freelancer Portfolio Website

A modern, responsive Freelancer Portfolio website built using **HTML5** and **CSS3**. This project showcases a professional portfolio with a clean user interface, responsive layout, and modern design principles.

## 📌 Project Overview

This website is designed for freelancers to present their profile, skills, projects, and contact information in a professional manner. The design follows modern UI/UX principles and is fully responsive across desktop, tablet, and mobile devices.

## ✨ Features

- Responsive Design
- Semantic HTML5
- External CSS3 Styling
- Modern Navigation Bar
- Hero Section
- About Me Section
- Skills Section
- Projects Showcase
- Contact Form
- Professional Footer
- Clean UI with Soft Shadows
- Flexbox & CSS Grid Layout
- Modern Typography
- Smooth Hover Effects

## 🛠 Technologies Used

- HTML5
- CSS3
- Google Fonts (Poppins)
- CSS Flexbox
- CSS Grid

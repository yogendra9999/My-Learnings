# 🌐 Resume Website

A modern and responsive **Resume Website** built using **HTML5** and **CSS3**. This project presents a professional online resume with a clean interface, showcasing personal information, skills, education, projects, and contact details.

---

## 📖 Project Overview

This Resume Website is designed to provide an attractive digital portfolio for a job seeker. It follows modern UI/UX principles and demonstrates responsive web design using only HTML5 and CSS3.

---

## ✨ Features

- Responsive Navigation Bar
- Hero Section with Profile Image
- About Me Section
- Education Information
- Career Objective
- Skills Showcase
- Projects Portfolio
- Responsive Footer
- Modern UI Design
- Hover Effects
- Semantic HTML5
- External CSS
- Flexbox Layout

# ERP Dashboard UI

A responsive ERP Dashboard UI built using **HTML5 and CSS3** as part of Task 19 of the HTML & CSS Practical Record.

## 📌 Project Overview

This project is a professional ERP dashboard interface designed for a manufacturing company. It provides a clean and organized view of business information through dashboard cards, analytics visuals, and a recent orders table.

The dashboard is designed to work across **desktop, tablet, and mobile devices**.

## ✨ Features

* Responsive ERP dashboard layout
* Sidebar navigation
* Top navigation bar
* Search box
* Admin profile section
* Dashboard welcome section
* Date display
* Statistics cards
* Total Revenue
* Total Orders
* Total Products
* Total Employees
* Revenue overview visual
* Sales by category visual
* Recent Orders data table
* Order status indicators
* Footer section
* Responsive tablet and mobile layouts
* Clean and organized CSS structure

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Grid
* CSS Flexbox
* Responsive Media Queries

## 📊 Dashboard Sections

### Sidebar

The sidebar provides navigation for:

* Dashboard
* HR Management
* Finance
* Inventory
* Sales
* Purchases
* Projects
* CRM
* Reports
* Settings

It also includes a support section.

### Top Navigation

The top navigation contains:

* Menu button
* Search box
* Admin profile
* Administrator information

### Statistics Cards

The dashboard displays four key business statistics:

* Total Revenue
* Total Orders
* Total Products
* Total Employees

### Analytics

The dashboard includes:

* Revenue Overview
* Sales by Category

The visuals are displayed using image assets stored inside the `assets` folder.

### Recent Orders

A responsive data table displays:

* Order ID
* Customer
* Date
* Amount
* Status

Different status styles are used for completed, processing, shipped, and pending orders.

## 📱 Responsive Design

The dashboard includes responsive layouts for:

* Desktop
* Tablet
* Mobile
* Small mobile screens

CSS media queries adjust the sidebar, navigation, cards, analytics sections, table, and footer according to screen size.

## 🎨 Design

The interface uses:

* Primary blue color
* White and gray backgrounds
* Rounded cards
* Subtle shadows
* CSS Grid and Flexbox
* Clean dashboard spacing
* Modern typography

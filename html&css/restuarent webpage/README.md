# 🍽️ TasteBites - Restaurant Website

## 📌 Project Overview

TasteBites is a modern and fully responsive restaurant website developed using **HTML5** and **CSS3**. The website provides an attractive user interface that showcases the restaurant, its menu, services, reservation section, and contact information while following modern web design principles.

---

## ✨ Features

* Responsive Navigation Bar
* Attractive Hero Section
* Why Choose Us (Features)
* About Restaurant Section
* Popular Menu Cards
* Reservation / Book a Table Section
* Contact Section
* Professional Footer
* Responsive Design for Desktop, Tablet, and Mobile
* Semantic HTML5 Structure
* Modern UI Design
* External CSS Styling

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Responsive Web Design

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.

No additional software or installation is required.

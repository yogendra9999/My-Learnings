# 💼 Business Card

## 📌 Overview

This project is a responsive digital business card built using **HTML5** and **CSS3**. It presents personal and professional information in a clean, modern layout. The design includes profile details, an about section, contact information, and social media links. :contentReference[oaicite:0]{index=0}

## ✨ Features

- Professional business card layout
- Profile image section
- About Me section
- Contact information
- Social media icons
- Responsive design
- Modern UI

## 🛠 Technologies Used

- HTML5
- CSS3
- Flexbox

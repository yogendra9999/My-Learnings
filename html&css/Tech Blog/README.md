# Tech Blog Homepage

A modern and responsive **Tech Blog Homepage** built using **HTML5** and **CSS3**. The website features a clean and professional layout designed for technology blogs, showcasing featured articles, latest posts, and essential navigation while following modern UI/UX principles.

## ✨ Features

- Responsive homepage design
- Professional navigation bar
- Hero section with featured blog post
- Latest Articles section
- Responsive blog cards
- Category and publication date badges
- Author profile and reading time
- Professional footer
- Modern typography
- CSS Flexbox and Grid layouts
- Smooth hover effects
- External CSS stylesheet
- Semantic HTML5 structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Google Fonts (Poppins)
- Font Awesome Icons

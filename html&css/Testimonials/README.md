# Testimonials Page

A modern and responsive **Testimonials Page** developed using **HTML5** and **CSS3**. This project showcases client testimonials with a professional UI, responsive layout, and modern design principles.

---

## 📌 Project Overview

The Testimonials Page is designed for a digital agency or business website to display customer feedback professionally. It features a clean layout, testimonial cards, a call-to-action section, and a responsive footer.

# 📸 LensCraft Photography Gallery

A modern and responsive **Photography Portfolio Website** built using **HTML5** and **CSS3**. The website showcases a professional photography gallery with an elegant user interface, making it suitable for photographers, studios, and creative professionals.

---

## 🚀 Live Features

* Responsive design for Desktop, Tablet, and Mobile
* Modern Hero Section with Background Image
* Transparent Navigation Bar
* Photography Gallery with Category Buttons
* About Photographer Section
* Photography Services Cards
* Call-to-Action (CTA) Section
* Professional Footer
* Smooth Hover Effects
* CSS Grid and Flexbox Layout
* Clean and Semantic HTML5 Structure

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Google Fonts (Poppins)
* CSS Flexbox
* CSS Grid
* Responsive Web Design

# LensCraft Photography

A modern and responsive photography portfolio website designed using HTML5 and CSS3. LensCraft Photography showcases professional photography services, creative work, and memorable moments through a visually appealing gallery.

## 📌 Project Overview

LensCraft Photography is a professional photography website created to showcase photography services and captured moments.

The website includes:

- Responsive navigation bar
- Hero section
- Photography gallery
- Gallery category buttons
- About section
- Photography services
- Call-to-Action section
- Contact information
- Social media links
- Responsive footer

The website introduces LensCraft Photography with the tagline "Capturing Moments, Creating Memories" and provides a button to explore the photography gallery. :contentReference[oaicite:2]{index=2}

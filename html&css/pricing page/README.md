# 💳 Pricing Page

A modern and responsive **Pricing Page** developed using **HTML5** and **CSS3**. This project presents three pricing plans with a clean layout, interactive pricing cards, a call-to-action section, and a professional footer. The page is fully responsive and designed following modern UI/UX principles. :contentReference[oaicite:0]{index=0}

---

## 📌 Project Overview

The Pricing Page helps users compare different subscription plans and choose the one that best fits their needs. It includes a navigation bar, pricing cards, a call-to-action section, and a footer with quick links.

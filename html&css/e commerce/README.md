# 🛍️ SSIT Shopify — E-Commerce Homepage

A modern and responsive **e-commerce fashion homepage** built using **HTML5 and CSS3**. The website showcases fashion products, categories, offers, customer benefits, store information, and a newsletter contact section.

## 📌 Project Overview

**SSIT Shopify** is a responsive fashion e-commerce homepage designed to provide a clean, modern, and user-friendly shopping experience.

The project focuses on:

* Modern e-commerce UI design
* Responsive layouts
* Semantic HTML5 structure
* Reusable UI components
* CSS Grid and Flexbox
* Modern typography and color palette
* Desktop, tablet, and mobile compatibility

## ✨ Features

* 📢 Announcement bar
* 🧭 Responsive navigation bar
* 🖼️ Hero section with call-to-action
* 👕 Shop-by-category section
* 🛍️ Featured products section
* ⭐ Product ratings and pricing
* 🛒 Add-to-cart buttons
* 🚚 Customer benefits section
* 🎯 Promotional CTA section
* ℹ️ About Us section
* 📧 Newsletter/contact section
* 🦶 Footer with useful links and contact information
* 📱 Responsive design for desktop, tablet, and mobile

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **Poppins Font**
* **CSS Grid**
* **CSS Flexbox**

> No JavaScript is used in this project.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Make sure the folder structure is maintained.
4. Open `index.html` in a browser.

You can also use the **Live Server** extension in VS Code for easier development.

# 📝 Student Registration Portal

## 📌 Overview

A complete student registration form developed using HTML5 and CSS3. It collects personal, academic, and contact details through a user-friendly interface.

---

## ✨ Features

- Student information
- Contact details
- Address section
- Course selection
- Terms & Conditions
- Submit button

## 🛠 Technologies Used

- CSS3

# 🚀 SaaS Landing Page

A modern, responsive SaaS Landing Page built using **HTML5** and **CSS3**. This project was developed as part of an HTML & CSS assignment and follows modern UI/UX principles with a clean and professional design.

---

## 📌 Features

- Responsive design for Desktop, Tablet, and Mobile
- Semantic HTML5 structure
- External CSS stylesheet
- Modern UI/UX
- Hero Section
- Features Section
- About Section
- Pricing Cards
- Testimonials
- Call-To-Action Section
- Contact Form
- Footer
- Smooth Hover Effects
- CSS Flexbox & Grid Layout

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts (Poppins)

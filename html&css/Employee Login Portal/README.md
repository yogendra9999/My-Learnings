# 🔐 Employee Login Portal

## 📌 Overview

A responsive employee login page created using HTML5 and CSS3. The interface is simple, clean, and suitable for employee authentication systems.

---

## ✨ Features

- Login form
- Email field
- Password field
- Remember Me option
- Forgot Password link
- Login button
